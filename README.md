# MY WORK FLOW
A professional single-page task management application built using
HTML5, CSS3 and Vanilla JavaScript ES Modules.

## Features

- Full CRUD operations
- Task search with debouncing
- Highlighted search matches
- Status and priority filtering
- Task sorting
- URL parameter persistence
- HTML5 drag-and-drop reordering
- localStorage persistence
- Schema migration support
- Keyboard shortcuts
- Undo and redo
- Command Pattern
- 20-action history stack
- Responsive design

## Technologies

- HTML5
- CSS3
- JavaScript ES6+
- ES Modules
- localStorage
- HTML5 Drag and Drop
- Browser History API
